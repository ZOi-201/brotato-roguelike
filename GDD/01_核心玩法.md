# 01_核心玩法

## 概述
《土豆兄弟》风格 2D 俯视角 roguelike 生存游戏。玩家控制角色在封闭竞技场中移动，武器自动攻击，在敌人波次中存活，波间购买装备强化自身。

## 核心循环
```
开局 → 战斗波(20-60s) → 敌死掉材料+经验 → 波结束
  ↓                                              ↓
商店(买武器/道具)                              获得材料
  ↓                                              ↓
升级选择(3-4抽1)  ←── 经验满槽触发的升级 ──────┘
  ↓
下一波 → ... → 第20波Boss → 通关胜利
```

## 美术
- 全部使用 Godot 内置几何图形（圆形、方形、三角等）占位
- 颜色区分：玩家(蓝)、敌人(红/橙/紫)、经验(绿)、材料(黄)

# 02_玩家系统

## 操作
- WASD 移动，8 方向
- 武器自动瞄准并攻击范围内最近敌人
- 无敌人时不攻击

## 属性
| 属性 | 说明 | 默认值 |
|---|---|---|
| Max HP | 最大生命 | 100 |
| HP | 当前生命 | 100（受击扣除，≤0游戏结束） |
| HP Regen | 每秒回血 | 0 |
| Damage % | 伤害倍率 | 100% |
| Attack Speed % | 攻速倍率 | 100% |
| Speed | 移动速度（px/s） | 150 |
| Dodge | 闪避率 | 0%（上限60%） |
| Armor | 减伤点数 | 0 |
| Luck | 幸运（影响掉落品质） | 0 |
| Harvesting | 收获加成（波结束时额外材料） | 0 |
| Lifesteal | 吸血百分比 | 0% |

## 实现
- 使用 `CharacterBody2D`
- 属性存储在一个 `Resource` 中（方便序列化和调试）

# 03_武器系统

## 机制
- 自动攻击，每种武器有独立攻击模式
- 最多同时持有 6 种武器
- 同种武器重复获取 = 升级（最高 Lv.4），升级提升伤害/范围/数量
- 武器按各自的攻速独立攻击

## MVP 武器列表
| 武器 | 攻击模式 | Lv.1 属性 |
|---|---|---|
| 手枪 | 朝最近敌人单发子弹 | 伤害 10, 射速 1.0/s, 射程 300 |
| 霰弹枪 | 扇形散射 3 颗 | 伤害 6×3, 射速 0.6/s, 射程 200 |
| 法杖 | 慢速穿透能量球 | 伤害 15, 射速 0.5/s, 穿透 |
| 匕首 | 快速近战刺击 | 伤害 20, 射速 2.0/s, 射程 80 |
| 弹弓 | 弹射子弹(命中弹向另一敌人) | 伤害 8, 射速 0.8/s, 弹射 1 次 |

## 升级效果（以手枪为例）
- Lv.1: 伤害 10, 射速 1.0/s
- Lv.2: 伤害 12, 射速 1.1/s
- Lv.3: 伤害 15, 射速 1.2/s, 双发
- Lv.4: 伤害 18, 射速 1.3/s, 双发, 穿透

# 04_道具系统

## 机制
- 被动加成，购买后永久生效
- 同种道具可叠加（部分道具有上限）
- 道具不占武器槽

## MVP 道具列表
| 道具 | 效果 | 可叠加 |
|---|---|---|
| 急救包 | +5 HP Regen | 是 |
| 咖啡 | +10% Attack Speed | 是 |
| 肌肉护腕 | +15% Damage | 是 |
| 跑鞋 | +20 Speed | 否 |
| 幸运草 | +5 Luck | 是 |
| 铁盾 | +3 Armor | 是 |
| 园艺手套 | +8 Harvesting | 是 |
| 肾上腺素 | 击杀后 3 秒 +30% Speed | 否 |
| 吸血牙 | +5% Lifesteal | 是（上限 50%） |
| 反伤甲 | 受击对周围敌人造成 5 伤害 | 否 |

# 05_敌人与波次

## 敌人类型
| 类型 | 行为 | 占位视觉 |
|---|---|---|
| 普通小怪 | 直线追玩家，速度中等 | 红色小圆（半径 12） |
| 冲锋怪 | 距离远时加速冲撞 | 橙色三角（朝玩家旋转） |
| 远程怪 | 保持距离，间歇射击 | 紫色方块（半径 14） |

## 波次规则
- 波次时长：20s + 波数×2s（即第 1 波 22s，第 20 波 60s）
- 敌人生成间隔随波数递减
- 每波敌人总数逐波递增
- 第 5、10、15 波：刷新精英怪（体型 1.5×，血量 3×，掉落 3×）
- 第 20 波：刷新 Boss（体型 3×，超高血量，特殊攻击）

## 掉落
- 击杀敌人 → 掉落绿色经验方块 + 低概率黄色材料方块
- 精英/Boss 掉落必定包含材料
- 掉落物半秒后自动向玩家吸附（磁铁效果）

# 06_商店系统

## 触发
每波战斗结束后自动进入商店。

## 规则
- 展示 4 个随机商品（武器和道具混排）
- 购买：花费材料获得商品
- 已持有的武器显示为升级（「手枪 Lv.2 → Lv.3」）
- 可花费 1 材料刷新一次，替换全部 4 个商品
- 价格公式：武器 Lv.1 约 15 材料，每级 +10；道具约 20-40 材料
- 关闭商店后进入下一波

---

# 07_升级系统

## 经验
- 击杀敌人掉落绿色经验方块，触碰获取
- 经验条满 → 升级，多余经验结转
- 所需经验：`level * 20 + 30`（第 1 级需 50 经验，逐级递增）

## 升级选择
- 每次升级从属性池随机抽 3-4 个选项，玩家选 1 个
- 属性等级越高，出现概率越低

| 属性 | 每级加成 | 最大等级 |
|---|---|---|
| Max HP | +5 | 无限 |
| HP Regen | +1/秒 | 10 |
| Damage % | +5% | 无限 |
| Attack Speed % | +5% | 无限 |
| Speed | +3 | 10 |
| Dodge | +3% | 20（上限 60%） |
| Armor | +1 | 无限 |
| Luck | +3 | 无限 |
| Harvesting | +3 | 无限 |

# 08_游戏流程

## 开始
→ 显示角色选择界面（MVP 仅一个角色，可直接开始）

## 战斗中
- HUD 显示：HP、经验条、波数、材料数、计时器
- 按 ESC 暂停

## 波间
→ 商店界面 → 关闭商店 → 下一波

## 升级触发
- 战斗中经验条满立即触发升级（暂停游戏，弹出选择界面）
- 选完属性后继续战斗
- 多余经验自动结转

## 结束
- HP ≤ 0：游戏失败，显示统计（击杀数、最高波数、获得材料总数）
- 通过第 20 波：游戏胜利，显示通关统计

# 09_技术约定

## 项目结构
```
scenes/           # .tscn 场景文件
scripts/          # .gd 脚本
  components/     # 可复用组件（Health, Movement, etc.）
  systems/        # 系统脚本（WaveManager, ShopManager, etc.）
assets/           # 美术音效资源（MVP 阶段用代码生成形状）
```

## 关键类
- `Player` — CharacterBody2D，处理输入、属性、武器管理
- `Enemy` — CharacterBody2D，AI 行为
- `Weapon` — Node2D，攻击逻辑基类
- `Projectile` — Area2D，子弹/投射物
- `GameManager` — Autoload，管理波次、状态
- `PlayerStats` — Resource，玩家属性数据
- `WaveManager` — Node，敌人生成调度
- `ShopUI` — CanvasLayer，商店界面
